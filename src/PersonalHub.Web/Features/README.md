# Features

Cada pasta aqui é uma fatia vertical (Vertical Slice) organizada por área e caso de uso, por exemplo `Students/CreateStudent/` ou `Lessons/RegisterLesson/`.

Uma fatia reúne o que o caso de uso precisa: página/componente, DTOs, validação, handler e acesso a dados específico. Regras de domínio reutilizáveis ficam fora dos componentes Razor.

Estrutura de referência: `.claude/docs/ARCHITECTURE.md`, seções 3 e 4.
