# Infrastructure

Implementações técnicas compartilhadas pelas features: persistência (PostgreSQL/EF Core), ASP.NET Core Identity, adapters de WhatsApp, jobs em segundo plano, relógio e observabilidade.

Regras de negócio não ficam aqui. Integrações externas ficam atrás de interfaces para que o domínio não dependa de fornecedores.

Estrutura de referência: `.claude/docs/ARCHITECTURE.md`, seções 3, 4 e 6.
